# Юридический ассистент ПСБ

За неделю разрабатываем: чат, который отвечает по документам и показывает источники своих выводов, если сведений недостаточно, он объясняет это или просит уточнение.

## Команда (можно менять)

| Участник | Ответственность |
|---|---|
| Александр | Документы, поиск, даты и редакции |
| Диана | Модель, сервер, проверка ответов и отправка на платформу |
| Дмитрий | Интерфейс, просмотр источников, запуск и демонстрация |

## Что должно получиться

- Веб-чат: вопрос → ответ → подтверждающий документ.
- Скрипт для автоматической проверки на платформе.
- Репозиторий с кодом и инструкцией запуска через Docker.
- PDF-презентация с примерами работы (сделаю через чатик).
