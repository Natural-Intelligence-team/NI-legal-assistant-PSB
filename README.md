# Юридический ассистент ПСБ

Прототип для сотрудников, которые проверяют условия договоров, внутренние регламенты и статьи законов. В чате можно открыть документ по ссылке и увидеть цитату в исходном тексте. Ответы формируются по учебной базе организаторов из `data/knowledge-base.zip`.

## Запуск

1. Установите Docker с Compose.
2. Создайте `.env` на основе `.env.example`. Внесите адрес и ключ OpenAI-совместимого API для **DeepSeek V4.1 Flash** и идентификатор модели, переданный поставщиком доступа. Храните ключ в локальном `.env`.
3. Из корня репозитория выполните команду.

   ```bash
   docker compose up --build
   ```

4. Откройте [http://localhost:8080](http://localhost:8080). Docker публикует только порт интерфейса `8080` на `127.0.0.1`. API на порту `8000` доступен интерфейсу внутри сети Compose.

| Переменная | Назначение |
| --- | --- |
| `LLM_BASE_URL` | Базовый адрес API. Сервер добавляет `/chat/completions`. |
| `LLM_API_KEY` | Ключ доступа к API. |
| `LLM_MODEL` | Идентификатор DeepSeek V4.1 Flash в API. |
| `TEMPERATURE` | Температура генерации. По умолчанию `0`. |
| `MAX_TOKENS` | Лимит токенов ответа. По умолчанию `2200`. |
| `LLM_TIMEOUT` | Тайм-аут запроса в секундах. По умолчанию `40`. |

Compose монтирует `data` в каталог `/data` контейнера только для чтения. Версии зависимостей зафиксированы в `requirements.txt` и `frontend/package-lock.json`.

## Архитектура

- React, TypeScript и Vite собирают интерфейс. Nginx отдаёт веб-страницу и передаёт запросы `/api` серверу FastAPI.
- При старте FastAPI загружает архив. Поиск ранжирует фрагменты по словам вопроса, учитывает номера договоров и периоды редакций. История диалога передаётся с каждым вопросом.
- Обработка v5 запрашивает у модели проверяемые выводы с цитатами. Сервер сверяет фрагменты с документами, повторяет запрос при ошибке проверки и возвращает частичный ответ, когда есть подтверждённые фрагменты. Интерфейс открывает источники по `source_id`.

## Проверка

1. В чате спросите «Какая арендная плата по договору с ООО „Северный Склад“ и до какого числа её нужно вносить?» В ответе ожидаются 450 000 ₽ в месяц и срок до 5-го числа текущего месяца с отсылкой к пунктам 3.1 и 3.2.
2. Нажмите на источник и найдите подсвеченную цитату в тексте договора.
3. Спросите «Какой размер пособия по беременности и родам?» В базе нет сведений для ответа на этот вопрос. Ассистент должен сообщить об их недостаточности.

## Ограничения

- База содержит 21 учебный документ. Полнота ответа зависит от наличия нужной нормы, редакции и условий в базе.
- Проверка подтверждает наличие цитаты в источнике. Применимость приведённого положения к сложным обстоятельствам нужно сверять по документу.
- Генерация зависит от доступности API и действующего ключа.
