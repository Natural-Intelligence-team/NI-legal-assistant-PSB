# Задачи команды
Для одной задачи/группы задач - одна ветка в main не коммитим, а только мержим пулл реквесты.

## Александр — документы и поиск

- [ ] **Загрузить и разбить документы.** Каждый фрагмент содержит текст, название документа и номер пункта, если он указан.
- [ ] **Сделать поиск по базе.** BM25 находит нужные положения и различает похожих контрагентов и договоры.
- [ ] **Добавить учёт дат и редакций.** Для события выбирается подходящая редакция; при нехватке даты можно запросить уточнение.
- [ ] **Связать документы.** Вместе с договором находятся его допсоглашения, вместе с регламентом — дополняющие документы.
- [ ] **Проверить качество поиска.** На примерах и новых формулировках отмечено, какие основания найдены и какие ошибки нужно исправить.

## Диана — модель и сервер

- [ ] **Подключить модель организаторов.** Запрос проходит через выданный API; адрес, ключ и имя модели берутся из настроек.
- [ ] **Сделать сервер и общий обработчик вопросов.** Чат и скрипт сдачи используют одну логику поиска и ответа; формат обмена согласован с Дмитрием.
- [ ] **Сделать ответы с подтверждениями.** Выводы опираются на документы; поддержаны история, уточнения, отказы и исправление неверной предпосылки.
- [ ] **Написать скрипт для платформы.** `solution.py` читает вопросы и базу, создаёт `submission.csv` с колонками `id,answer`; нужные Python-файлы лежат в корне ZIP.
- [ ] **Проверить ответы и отправить пробный сабмит.** Проверены смысл, цитаты, даты, отказы и скорость; фактическая оценка платформы записана.

## Дмитрий — интерфейс и сдача

- [ ] **Подготовить макет и React-проект.** Понятно, где задать вопрос, прочитать ответ и открыть источник.
- [ ] **Сделать и подключить чат.** Видны ожидание, ответ и ошибка; можно продолжить разговор или начать новый.
- [ ] **Добавить просмотр источников.** Из ответа открывается документ и показывается подтверждающий фрагмент.
- [ ] **Подготовить запуск и упаковку.** Есть Docker Compose, инструкция и сборка архива; другой участник запускает проект по инструкции.
- [ ] **Подготовить презентацию и демонстрацию.** Показаны ответ, отказ и вопрос с датой; ссылки работают, все трое могут объяснить решение.
